# HnPsdk / hn 工程说明

本文档概述仓库组成、固件与上位机职责、串口协议入口及开发与打包方式。

---

## 1. 工程定位

- **固件**：STM32H7 载板，集成 DJI PSDK 样例与自定义数传业务；通过 UART 与上位机交互，支持航线 KMZ、飞行控制、水泵、喷洒角度、舵机摆动等。
- **上位机**：`serial_ota/` 目录下基于 **PyQt5 + pyserial** 的客户固件升级工具，用于通过 CP210x 虚拟串口执行固件升级。
- **协议说明**：串口固件升级以 `docs/serial_ota_protocol.md` 为对外协议基准；业务数传实现见 `DJI_PSDK/module_sample/custom_serial/`。

---

## 2. 目录结构（核心）

| 路径 | 说明 |
|------|------|
| `APP/` | STM32 应用与 Cube/Keil 工程相关源码 |
| `DJI_PSDK/module_sample/custom_serial/` | 业务：0x10/0x01 航线上传、0x02~0x06 控制、0x05 状态、0x11~0x14 航线查询/删除等 |
| `DJI_PSDK/module_sample/utils/util_crc.c` | CRC16（Modbus），用于业务数传帧校验 |
| `BSP/route_storage.c` / `route_storage.h` | 航线 KMZ Flash 存储（保存/擦除/上电恢复到 RAM） |
| `docs/serial_ota_protocol.md` | **串口固件升级协议**：握手、传输、校验、复位流程 |
| `serial_ota/` | 客户固件升级工具源码、依赖、打包脚本和单文件 exe |

## 3. 固件侧要点

### 3.1 串口

- 自定义数传初始化使用 **UART1**（`SerialHandler_InitService(DJI_HAL_UART_NUM_1, …)`），典型波特率 **115200**（以 `custom_serial` 中 `CUSTOM_BAUDRATE` 与文档为准）。

### 3.2 帧与 CRC

- 帧头/帧尾：`0x8855`（小端在总线上为 `55 88`）。
- CRC16 覆盖：`MsgType` +（若含 DroneID）`DroneID` + `PayloadLen(4B)` + **完整 Payload**；与 `Util_Crc16Calculate` 一致。
- 载板主动下发且无 DroneID 字节的类型（如 0x05、0x12、0x14）在 `MsgType_HasDroneId` 中与 `SerialHandler_Send` 保持一致，否则 CRC 与解析会错位。

### 3.3 消息 ID（摘要）

| 方向 | MsgID | 含义（摘要） |
|------|-------|----------------|
| 上位机→载板 | 0x10 | 开始 KMZ：4B 总长 或 5B 总长+槽号 |
| 上位机→载板 | 0x01 | KMZ 分片 |
| 上位机→载板 | 0x02 / 0x03 / 0x04 / 0x06 | 飞控、水泵、喷洒角、摆动 |
| 上位机→载板 | 0x11 / 0x13 | 查询航线槽、按槽删除 |
| 载板→上位机 | 0x05 | 周期状态 |
| 载板→上位机 | 0x12 / 0x14 | 查询应答、删除 ACK |

串口固件升级流程见 **`docs/serial_ota_protocol.md`**。

### 3.4 航线存储

- 多槽 RAM 镜像 + `RouteStorage_Save` / `RouteStorage_Erase` / `RouteStorage_Init`；槽数量与 `CUSTOM_ROUTE_SLOT_COUNT` / `ROUTE_STORAGE_SLOT_COUNT` 一致（当前为 5）。

## 4. 上位机

PyQt5 固件升级工具位于 [`serial_ota/`](../serial_ota/) 目录，包含源码、依赖、打包脚本和客户可直接运行的 `SolarCleanFirmwareUpdater.exe`。

详见 **[`serial_ota/README.md`](../serial_ota/README.md)**。

---

## 5. 联调与维护建议

1. 修改串口升级协议时同步更新：`DJI_PSDK/APP/serial_ota/`、`serial_ota/`、`docs/serial_ota_protocol.md`。
2. 联调检查项：波特率、DroneID（上位机可选多机，默认首机 0x31）、CRC 覆盖范围、各 MsgID 载荷长度。
3. 固件编译与烧录按团队现有 Keil/STM32Cube 流程；上位机升级 Python 或 PyQt 后建议重新完整测串口与打包。
